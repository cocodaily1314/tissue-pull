# 抽啊抽 · 紙巾挑戰

限時手速超休閒：抽紙巾計張數，或者捲紙計長度——奶油風畫面、結果圖可下載分享 Threads。

## 一句玩法
**Mode A** 向上掃抽出紙巾計張數；**Mode B** 拖曳開卷計長度。限時 18 秒，手速見真章。

## 點玩
1. 用瀏覽器打開 `index.html`（純 HTML+Canvas，毋須安裝／build）
2. 主選單揀 **Mode A · 抽紙巾計張數** 或 **Mode B · 卷紙計長度**
3. 倒數 3 秒後開始：
   - **Mode A**：手指／滑鼠**向上掃／拖**，每完成一次上拉就 +1 張；畫面大數字即時顯示張數
   - **Mode B**：**任意方向拖曳**開卷，長度按實際拖曳距離累積（cm／m 自動切換）
4. 時間到 → 結果卡（成績、速率、搞笑港式評級）→ 「下載結果圖」

## 評分
| 模式 | 計分 | 港式評級（由低至高） |
|------|------|----------------------|
| A 抽紙巾 | 完成上拉次數＝張數；速率＝張／秒 | 紙都未郁 → 手殘紙奴 → 街坊抽紙手 → 急症室級 → 紙巾粉碎機 → 全家裝清貨王 → 紙巾之神 |
| B 卷紙 | 拖曳像素距離 × 0.05＝長度 cm；≥100cm 顯示為 m | 抹嘴都唔夠 → 街坊衛生標兵 → 廁紙刺客 → 捲紙馬拉松 → 連卷大王 → 廁紙傳說 |

計分跟住你嘅實際動作：冇抽／冇拖就唔會加分。

## 點分享
完場撳「**下載結果圖**」儲存直向 PNG，再上傳 Threads 挑戰朋友手速。亦可「再玩一次」或「返主選單」轉模式。
